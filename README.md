# کالانو

اپلیکیشن واسطه‌گری کالا — کل ایران

---

## 📌 درباره پروژه

کالانو یک پلتفرم واسطه‌گری است که خریدار و فروشنده را در سراسر ایران به هم وصل می‌کند.

مدیریت: شخصی (اختصاصی)

---

## 🎯 امکانات

- دسته‌بندی جامع (املاک، خودرو، موبایل، لباس، خدمات، ...)
- ثبت آگهی توسط فروشندگان
- جستجو و فیلتر پیشرفته
- اشتراک ماهانه برای فروشندگان
- پرداخت کارت‌به‌کارت
- پنل مدیریت اختصاصی

---

## 💎 پلن‌های اشتراک

| پلن | قیمت ماهانه (تومان) | امکانات |
|-----|---------------------|---------|
| رایگان | ۰ | ۲ آگهی |
| برنزی | ۲۹۰,۰۰۰ | ۲۰ آگهی + نشان برنزی |
| نقره‌ای | ۵۹۰,۰۰۰ | ۱۰۰ آگهی + نشان نقره‌ای |
| طلایی | ۱,۲۹۰,۰۰۰ | آگهی نامحدود + نو شدن خودکار |
| الماسی | ۲,۹۰۰,۰۰۰ | بنر + تیک آبی + صفحه اختصاصی |
| ویژه (برندها) | ۵,۹۰۰,۰۰۰ | اسپانسر + تبلیغات پاپ‌آپ |

---

## 🛠️ تکنولوژی

- **Frontend:** React + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Host:** Liara / ArvanCloud
